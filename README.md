# Credit Card Fraud Risk Analysis – Power BI

## 📊 Project Overview

This project presents an interactive **Credit Card Fraud Risk Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes transaction data to identify fraud patterns, fraud types, risk levels, transaction amounts, states, and monthly fraud trends.

## 🎯 Objectives

- Analyze fraudulent credit card transactions
- Identify the most common fraud types
- Analyze fraud risk levels
- Compare fraudulent transactions across different states
- Analyze monthly fraud trends
- Identify high-risk transactions
- Understand transaction amount patterns

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Excel / CSV Dataset

## 📈 Dashboard Features

### Key Performance Indicators

- **Fraud Rate:** 28.60%
- **Fraudulent Transactions:** 286
- **Critical Risk Transactions:** 10.70%
- **Fraudulent Transaction Amount:** 3M
- **Top Fraud Type:** Card Not Present

### Visualizations

- Total Transaction Amount by Fraud Type and Transaction Category
- Total Transaction Amount by Fraud Risk
- Fraudulent Transactions by State
- Fraudulent Transactions by Month
- Fraud Type and Transaction Category Analysis
- Interactive filters for:
  - Fraud Type
  - State
  - Merchant Name

## 🔍 Key Insights

- **Card Not Present** is the top fraud type.
- The dashboard shows different fraud risk levels including Low, Medium, High, and Critical.
- Maharashtra has the highest number of fraudulent transactions among the displayed states.
- Fraudulent transactions vary significantly across different months.
- Interactive filters allow users to explore fraud patterns by state, fraud type, and merchant.
